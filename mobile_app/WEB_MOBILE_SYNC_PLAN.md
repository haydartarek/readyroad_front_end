# خطة مزامنة Web إلى Mobile

## الهدف

جعل `mobile_app` متوافقًا وظيفيًا مع الميزات المشتركة في `web_app`، مع اعتبار Backend والعقود المشتركة مصدر الحقيقة. نسخة `web_app` للقراءة فقط ولا يسمح بتعديلها ضمن هذه الخطة.

## قواعد التنفيذ

- التعديل داخل `mobile_app` فقط.
- لا نسخ احتياطية، ولا نسخ ملفات بديلة، ولا حذف تغييرات المستخدم الحالية.
- لا Commit أو Push أو Deployment ضمن التنفيذ إلا بطلب منفصل.
- لا نضع بيانات وهمية لتعويض API أو Backend غير موجود.
- كل دفعة صغيرة لها فحص مستهدف قبل الانتقال إلى الدفعة التالية.
- عند اكتشاف مشكلة خارج الدفعة الحالية، تسجل في الخطة ولا تعالج حتى يحين دورها.
